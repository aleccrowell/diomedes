API: Data sources and schemas

Diomedes.LAP_SCHEMA — Constant
LAP_SCHEMA

Lap times, as column => element type pairs: one row per car per lap (fetch_laps). Ids match RESULT_SCHEMA's.

PIT_SCHEMA

Pit stops, as column => element type pairs: one row per stop, with the in-lap (fetch_pit_stops). Ids match RESULT_SCHEMA's.

Diomedes.RESULT_SCHEMA — Constant
RESULT_SCHEMA

The common long-format results table, as column => element type pairs: one row per competitor per timed stage (an F1 race, a WRC special stage). Every DataSource returns it from fetch_results; see validate_results.

Diomedes.ErgastCSV — Type
ErgastCSV(dir; include_indy500 = false)

F1 results from a local Ergast-format CSV dump (results.csv, races.csv, drivers.csv, constructors.csv, status.csv). Useful offline and for checking parity with the legacy Python pipeline, which used such a dump.

IDs use Ergast's driverRef/constructorRef strings so they match JolpicaF1. If the dump has lap_times.csv (1996+), suspended_ms is each race's red-flag suspension detected from lap times (see suspension_ms); it is missing for races without lap times. The Indianapolis 500 (1950–1960) is excluded unless include_indy500 = true (see INDY500).

source
Diomedes.JolpicaF1 — Type
JolpicaF1(; base_url, cache_dir, refresh=false)

F1 race results from the Jolpica API (https://github.com/jolpica/jolpica-f1), the maintained successor to the Ergast API, with the same schema. Covers 1950 to the present.

Unauthenticated limits are 4 req/s burst and 500 req/hour sustained. A full history is roughly 300 paged requests; responses are cached, so this is a one-off cost. Pass refresh=true to re-fetch (e.g. the in-progress season). suspended_ms (red-flag suspension included in official times, see suspension_ms): races whose winner's average lap is anomalously slow against the fastest lap (suspect_suspension) have their lap times fetched and checked, a few extra requests per season; other races get 0. Races without fastest-lap data (before 2004) get missing. The Indianapolis 500 (1950–1960) is excluded unless include_indy500 = true (see INDY500).

source
Diomedes.fetch_laps — Method
fetch_laps(src::JolpicaF1, seasons) -> DataFrame

Lap times (LAP_SCHEMA) from Jolpica's laps endpoint, which has them from 1996: about 11 paged requests per race (100 timings per page), cached. Ids match fetch_results(src, …) and ErgastCSV, so seasons from the two sources can be combined. Races without lap data are skipped.

source
Diomedes.fetch_pit_stops — Method
fetch_pit_stops(src::JolpicaF1, seasons) -> DataFrame

Pit stops (PIT_SCHEMA) from Jolpica's pitstops endpoint (2011 on), one or two requests per race, cached. duration_ms is missing when the duration isn't a plain time (e.g. a stop during a red flag).

source
Diomedes.WRCTiming — Type
WRCTiming(; championship="World Rally Championship", series="wrc", ...)

Stage times from the timing API behind wrc.com (hosted by Red Bull). It is undocumented; the endpoints follow OpenWRC (github.com/jixy2012/OpenWRC) and rallydatajunkie.com's notes on the WRC live timing API.

Coverage: WRC 2018 onwards and the European Rally Championship 2022 onwards (WRCTiming(championship = "European Rally Championship", series = "erc")).

Each completed special stage is one stage_id. machine_id is the vehicle model as typed by the organisers, normalised (normalise_model: "i20 Coupé WRC " → "I20 COUPE WRC"); class is the entry group (Rally1, Rally2, ...). The cleaner identifiers are manufacturer (e.g. "Toyota") and entrant (works team or privateer), so a machine grouping such as manufacturer × class × season can be built with prepare_gaps(...; machine_key). Stage times exclude penalties. Only stages with status "Completed" are included; cancelled and interrupted stages (which get notional times) are skipped.

About 300 requests per season; responses are cached.

Diomedes.INDY500 — Constant

The Indianapolis 500 counted towards the F1 World Championship from 1950 to 1960, but it was effectively a separate series: different cars and a field of drivers who mostly raced only there. The F1 adapters drop it by default.

Diomedes.suspect_suspension — Method
suspect_suspension(winner_ms, laps, fastest_lap_ms) -> Bool

Cheap screen for sources without lap times in the results: flags a race whose winner's average lap is more than 1.25× the fastest lap. Normal races run at ~1.05–1.25× (safety cars included), so this only picks candidates, whose lap times are then fetched and checked with suspension_ms.

source
Diomedes.suspension_ms — Method
suspension_ms(car_laps) -> Float64

Total suspended time in a race, from car_laps: a collection of per-car vectors of lap times (ms). Returns 0.0 if no stoppage is found.

source
Diomedes.lap_hours_lost — Method
lap_hours_lost(official_ms, laps_ms) -> Float64

Whole hours missing from a car's lap times (ms), from its official race time: Jolpica's lap time strings drop the hours of a lap with a red flag in it ("22:30.5" for 1:22:30.5). Complete lap times otherwise sum to the official time.

source
Diomedes.normalise_model — Method
normalise_model(s)

Canonical form of a free-text vehicle model: accents stripped, upper case, runs of spaces collapsed, and "RALLY 1" written "RALLY1".

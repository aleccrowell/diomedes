Diomedes.jl

Bayesian models of driver vs machine performance in motorsport, in Julia with Turing.jl.

The question: how much of a result is the driver and how much is the car? Every model here has crossed random effects for competitors (drivers) and machine-seasons (a car in one season), fitted to public timing data: Formula 1 from 1950 (Jolpica / Ergast) and the WRC and ERC rally championships (the wrc.com timing API).

How the package is organised

Data flows through three layers, and only the first knows which series it is looking at:

  1. Sources fetch raw data from a public API or local files and normalise it into a common long-format table, one row per competitor per timed stage (RESULT_SCHEMA). See Data.
  2. Preparation (prepare* functions) turns that table into the inputs of one model: an outcome per row and integer indices for competitors, machine-seasons and races.
  3. Models are Turing models over those inputs, each with a fit_* function and summary helpers.

Diomedes

Bayesian models of competitor vs machine performance in motorsport.

Data flows through three layers:

  1. Sources (src/sources/) fetch raw data from a public API or local files and normalise it into the common long-format results schema (src/schema.jl).
  2. Preparation (prepare, prepare_gaps, prepare_retirements, prepare_laps) turns a results table into one model's inputs: an outcome per row plus integer indices for competitors, machine-seasons and races.
  3. Models (fit_effects, fit_gaps, fit_paceloss, fit_retirement, fit_laps) are Turing models over those inputs and know nothing about which series the data came from.

Adding a new series means writing one source adapter; nothing downstream changes.

source

Conventions

  • Units. Pace effects are in % of race (or lap) time, on a log scale: 100·log(T / T_ref). Negative is faster. The retirement model's effects are on the log-hazard scale.
  • Identification. Driver effects sum to zero, so they are relative to the average driver in the data. Car-season effects sum to zero within each season: with race intercepts, only differences between cars in the same season are identified. Drivers who change teams link the seasons together.
  • Issue numbers (#9, #15, ...) in docstrings and comments refer to the GitHub issues where each piece was designed and evaluated.

Scripts

The scripts in scripts/ run the package's analyses on the full data, write to output/ (gitignored), and document their arguments in a header comment. Run them with julia --project scripts/<name>.jl ....

ScriptPurpose
legacy_parity.jlChecks the z-score port against the original Python pipeline
gap_fit.jlFits a gap or pace + loss model (F1 or WRC); chain k / combine
compare_gap_fits.jlLead-lap finishers only vs with lapped cars
loo_compare.jlPSIS-LOO comparison of fitted gap models
kfold.jlGrouped K-fold CV: fold runs, then compare
mode_check.jlWhether a fit depends on where its chains start
era_paths.jlPer-season incident rate, loss size and pace scale
incident_diagnostic.jlPosterior incident probabilities per result, by season
age_curve.jlThe population career curve
career_slopes.jlDrivers with the largest career slopes
retire_fit.jlFits the retirement model and writes reliability and incident tables
selection_check.jlWhether dropping retirements biases the pace effects
lap_fit.jlFits the lap-time model, checkpointed, optionally warm-started
lap_compare.jlLap-model fits against each other or the race model
export_site.jlExports posterior summaries of a fitted race model for the site's Findings pages (docs/src/assets/data/)

Model names (pl_dur_rw_kappa, ...) are parsed by model_spec.
